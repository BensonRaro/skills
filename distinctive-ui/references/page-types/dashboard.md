# Dashboard

Primary goal: fast comprehension and task completion.

Design:
- establish a visual focal point;
- use KPI cards only when they are genuinely useful;
- prefer meaningful chart narratives over chart decoration;
- separate global navigation from contextual actions;
- make dense tables readable;
- include empty/loading/error states.

Distinctive directions:
- dark observatory;
- editorial analytics;
- calm clinical;
- warm academic;
- operations command center;
- translucent spatial dashboard.

Do not blindly reproduce the familiar "4 KPI cards + line chart + table" template.

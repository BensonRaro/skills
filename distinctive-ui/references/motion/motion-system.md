# Motion System

Motion hierarchy:

Level 1 — feedback
- hover;
- focus;
- press;
- loading;
- validation.

Level 2 — transition
- section reveals;
- page transitions;
- chart changes;
- navigation state.

Level 3 — storytelling
- pinned scroll;
- camera movement;
- object transformation;
- immersive scenes.

Rule:
If removing the animation makes the product clearer, remove it.

Use easing consistently and avoid excessive simultaneous movement.

Always support reduced motion.

# Accessibility Checklist

Before completion verify:
- semantic headings;
- label every form control;
- keyboard navigation;
- visible focus;
- sufficient contrast;
- target sizes;
- screen-reader meaningful names;
- error messages;
- reduced motion;
- no information conveyed only by color;
- mobile zoom/text scaling;
- dialogs trap and restore focus correctly.

Visual sophistication must never be purchased with inaccessible interaction.

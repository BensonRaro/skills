# Glass / Layered Translucency

Glass works when it communicates depth.

Use:
- translucent surfaces;
- subtle borders;
- backdrop blur;
- visible background context;
- different opacity levels for hierarchy.

Build a material hierarchy:
1. canvas;
2. ambient layer;
3. primary surface;
4. elevated surface;
5. active/focused surface.

Avoid making every element glass.

Distinctive adaptation:
Use glass only for controls that conceptually float above the environment, while core data panels remain opaque for readability.

# Dark Premium

Dark interfaces need hierarchy, not just black backgrounds.

Use:
- near-black base;
- restrained surfaces;
- luminous data accents;
- subtle dividers;
- generous negative space;
- strong numeric typography.

Avoid:
- every surface being #111;
- neon everywhere;
- excessive glow;
- low contrast gray text.

Distinctive adaptation:
Make one data type the visual protagonist, such as revenue, attendance, patient flow, course completion, or inventory velocity.

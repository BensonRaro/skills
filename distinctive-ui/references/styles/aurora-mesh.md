# Aurora / Mesh

Use luminous gradients as environmental lighting rather than wallpaper.

Study:
- large low-contrast radial fields;
- blurred color transitions;
- dark or near-white foundations;
- controlled accent zones;
- gradients that guide attention toward content.

Do:
- keep text areas readable;
- vary gradient scale;
- use gradients to establish depth;
- combine with crisp typography.

Avoid:
- identical purple-blue blobs behind every section;
- excessive blur;
- gradient on every card.

Distinctive adaptation:
Use an aurora field as a navigational signal: each product area receives a subtle light zone, while the actual UI stays crisp.

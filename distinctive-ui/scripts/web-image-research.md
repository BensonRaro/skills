# Web Image Research Procedure

When a required image is not present locally:

1. Search the web for a specific visual need.
2. Prefer sources with explicit reuse/commercial licensing.
3. Inspect the source page, not just the search snippet.
4. Record the source URL and license in project notes.
5. Download only the specific asset needed.
6. Avoid scraping or building a local stock-image mirror.
7. Avoid logos, identifiable people, artwork and branded products when rights are uncertain.
8. Optimize the chosen image before shipping.

Recommended query structure:

`[subject] + [visual style] + [lighting] + [composition] + [use case]`

Examples:
- `modern school architecture editorial photography warm morning`
- `premium medical technology dark blue product photography`
- `minimal ecommerce ceramic product studio lighting`
- `student studying library cinematic editorial photography`

If a suitable Unsplash image is found, verify the current Unsplash terms and any depicted third-party rights before production use.

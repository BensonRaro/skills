# Inspiration Audit Script Prompt

Use this prompt when you want OpenCode to perform the inspiration pass before coding:

Read `@distinctive-ui`.

Then recursively inspect every image under `inspiration/images/`.

Do not filter the images by the requested page category.

Create:
1. 5–10 observations across the entire image pool;
2. 3–5 combinations of ideas that could work for the requested product;
3. one final visual thesis;
4. a short list of ideas deliberately rejected because they are too generic or too close to a reference.

Then propose the page architecture and only after that start implementation.

The final design must be a synthesis, not a copy.

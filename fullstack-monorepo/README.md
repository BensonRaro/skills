# Full-Stack Monorepo Skill

Reusable OpenCode skill for production-ready MERN/PERN-style two-service monorepos.

## Includes
- monorepo architecture
- route/controller/service separation
- optional repository layer
- focused file-size discipline
- Express `app.ts` / `server.ts` separation
- Helmet, CORS, cookie-parser, request logging, health checks
- environment-variable discipline
- validation, authentication, authorization
- secure API conventions
- database practices
- frontend feature architecture
- centralized API access
- testing priorities
- documentation standards
- production-readiness checks

## Install

Copy this directory to:
```text
.opencode/skills/fullstack-monorepo/
```

Then use:
```text
Read @fullstack-monorepo.
```

Keep project-specific rules in that project's `AGENTS.md`.
